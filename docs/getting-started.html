Getting started

Install the client for your language, start the bundled mock server, and run a first program that authenticates, discovers a storage and writes a resource. It takes about five minutes.

Requirements

  • Java 17+ (one runtime dependency: Jackson databind)
  • JavaScript/TypeScript: Node.js 20+, any modern browser, Deno or Bun (no runtime dependencies)
  • C++: a C++20 compiler and CMake 3.21+. nlohmann/json is required; libcurl and OpenSSL are optional.
  • Rust 1.85+ (edition 2024, tokio)
  • Go 1.23+ (no third-party dependencies)
  • Python 3.10+ (httpx; the crypto extra adds cryptography)
  • C#: .NET 10 (one dependency: BouncyCastle.Cryptography, for Ed25519)
  • Swift 6.0+ on macOS 13, iOS 16 or Linux (one dependency: swift-crypto, which is CryptoKit on Apple platforms)

Start a server to talk to

The repository includes a complete in-memory LWS server for development. It needs Node.js 22+ and has no dependencies:

git clone https://github.com/ebremer/lws-client.git
node lws-client/testing/mock-server/server.mjs --port 8787
# LWS mock server listening on http://localhost:8787

Its storage root is http://localhost:8787/root/. Every request needs an access token, which is exactly what the client's authenticator takes care of.

Your first program

The program below generates a self-signed did:key identity, lets the client handle the 401 → token exchange flow, discovers the storage from a resource URL, creates a container and a text file, and reads the file back with its metadata.

import com.ebremer.lws.Body;
import com.ebremer.lws.CreateOptions;
import com.ebremer.lws.LwsClient;
import com.ebremer.lws.Resource;
import com.ebremer.lws.StorageDescription;
import com.ebremer.lws.auth.KeyPairs;
import com.ebremer.lws.auth.SelfSignedCredentials;
import com.ebremer.lws.auth.TokenExchangeAuthenticator;
import java.net.URI;

public class HelloLws {
    public static void main(String[] args) {
        SelfSignedCredentials credentials = SelfSignedCredentials.didKey(KeyPairs.generateP256());
        LwsClient client = LwsClient.builder()
                .authenticator(TokenExchangeAuthenticator.of(credentials))
                .build();
        System.out.println("agent:   " + credentials.agent());

        StorageDescription storage = client.discoverStorage(URI.create("http://localhost:8787/root/"));
        System.out.println("storage: " + storage.id() + "  root: " + storage.storageRoot());

        URI folder = client.createContainer(storage.storageRoot(), CreateOptions.slug("hello-world")).location();
        URI file = client.create(folder, Body.of("Hello, LWS!"), "text/plain", CreateOptions.slug("hello.txt")).location();
        System.out.println("created: " + file);

        Resource resource = client.read(file);
        System.out.println(resource.text() + "  (etag " + resource.etag().orElse("-")
                + ", parent " + resource.metadata().parent().orElse(null) + ")");
    }
}

use lws_client::{Client, SelfSignedCredentials, TokenExchangeAuthenticator, Url, crypto::SigningKey};

#[tokio::main]
async fn main() -> lws_client::Result<()> {
    let credentials = SelfSignedCredentials::did_key(SigningKey::generate_p256()?);
    println!("agent:   {}", credentials.agent());
    let client = Client::builder()
        .authenticator(TokenExchangeAuthenticator::new(credentials))
        .build()?;

    let storage = client.discover_storage("http://localhost:8787/root/").await?;
    let root = storage.storage_root()?.clone();
    println!("storage: {}  root: {root}", storage.id);

    let folder = client.create_container(&root).slug("hello-world").await?.location;
    let file = client
        .create(&folder, "Hello, LWS!", "text/plain")
        .slug("hello.txt")
        .await?
        .location;
    println!("created: {file}");

    let resource = client.read(&file).await?;
    let etag = resource.metadata.etag.as_deref().unwrap_or("-");
    let parent = resource.metadata.parent().map(Url::as_str).unwrap_or("-");
    println!("{}  (etag {etag}, parent {parent})", resource.text()?);
    Ok(())
}
package main

import (
	"context"
	"fmt"
	"log"
	"strings"

	lws "github.com/ebremer/lws-client/go"
)

func main() {
	ctx := context.Background()
	key, err := lws.GenerateP256Key()
	if err != nil {
		log.Fatal(err)
	}
	credentials, err := lws.NewDIDKeyCredentials(key, nil)
	if err != nil {
		log.Fatal(err)
	}
	client := lws.NewClient(lws.WithAuthenticator(lws.NewTokenExchangeAuthenticator(credentials, nil)))
	fmt.Println("agent:  ", credentials.Agent())

	storage, err := client.DiscoverStorage(ctx, "http://localhost:8787/root/")
	if err != nil {
		log.Fatal(err)
	}
	root, err := storage.StorageRoot()
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("storage:", storage.ID, " root:", root)

	folder, err := client.CreateContainer(ctx, root, lws.Slug("hello-world"))
	if err != nil {
		log.Fatal(err)
	}
	file, err := client.Create(ctx, folder.Location, strings.NewReader("Hello, LWS!"), "text/plain", lws.Slug("hello.txt"))
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("created:", file.Location)

	res, err := client.Read(ctx, file.Location)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%s  (etag %s, parent %s)\n", res.Text(), res.ETag, res.Parent)
}

What just happened

  1. Identity. SelfSignedCredentials.didKey created an agent whose identifier is derived from a fresh P-256 public key. It signs short-lived JWT credentials (sub = iss = client_id) as described in the self-signed authentication suite.
  2. Challenge. The first request got 401 with WWW-Authenticate: Bearer as_uri="…", realm="…". The authenticator checked that the URL is inside the realm and fetched /.well-known/lws-configuration.
  3. Token exchange. It posted the signed credential to the token endpoint (RFC 8693), received an access token for the realm, cached it, and retried the request. Later requests send the token immediately.
  4. Discovery. The response's Link: rel="https://www.w3.org/ns/lws#storage" led to the storage description, whose StorageRoot service is the root container.
  5. Create and read. POST to the container returned 201 Created with a Location. GET returned the content plus an ETag and up/linkset/type links.
