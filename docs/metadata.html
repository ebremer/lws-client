Metadata & linksets

LWS keeps a resource's metadata as typed links in a dedicated linkset resource (application/linkset+json, RFC 9264). You find it through rel="linkset" and change it with JSON Patch.

Kinds of metadata

KindExamplesWho changes it
System managedlinkset, type (Container/DataResource), format, size, modifiedServer only
Coreup, items, title, creatorClient, subject to server restrictions
User-defineddescribedby, license, extension relation URIsClient
{
  "linkset": [{
    "anchor": "https://storage.example/alice/personalinfo.json",
    "describedby": [{ "href": "https://storage.example/schemas/personal-info.json" }],
    "license": [{ "href": "https://creativecommons.org/licenses/by/4.0/" }]
  }]
}

Reading a linkset

readLinkset(resourceUrl) discovers the linkset URL with HEAD, fetches it and returns a document with the linkset URL, its ETag, and the server's Allow and Accept-Patch headers. The Linkset model keeps unknown members, so a read-modify-write round trip loses nothing.

LinksetDocument doc = client.readLinkset(url);      // HEAD for rel="linkset", then GET
System.out.println(doc.url() + " " + doc.etag() + " " + doc.allow() + " " + doc.acceptPatch());

for (Link link : doc.linkset().links()) System.out.println(link.rel() + " → " + link.href());
List<String> shapes = doc.linkset().targets("describedby").stream().map(Linkset.LinkTarget::href).toList();
const doc = await client.readLinkset(url);       // HEAD for rel="linkset", then GET
console.log(doc.url, doc.etag, doc.allow, doc.acceptPatch);

for (const link of doc.linkset.links()) console.log(link.rel, "→", link.href);
const shapes = doc.linkset.targets("describedby").map((target) => target.href);
console.log(shapes);

Patching a linkset

JSON Patch is the mandatory linkset update format. Two details catch most people:

  • Escape relation URIs. Extension relation types are URIs and contain /, which JSON Pointer uses as a separator. Build paths with JsonPointer, which escapes / as ~1 and ~ as ~0. For example, /linkset/0/https:~1~1example.org~1rel~1reviewer/-.
  • Add versus append. add on an existing member replaces it. Append to an existing relation with the /- array index, and create a new relation with a one-element array.
LinksetDocument doc = client.readLinkset(url);
String rel = "https://example.org/rel/reviewer";          // extension relation types are URIs
Map<String, String> reviewer = Map.of("href", "https://id.example/bob");

// JsonPointer escapes "/" in the relation URI as "~1".
// "add" on an existing member replaces it, so append with "/-" when the relation exists.
JsonPatch patch = doc.linkset().targets(rel).isEmpty()
        ? JsonPatch.builder().add(JsonPointer.of("linkset", "0", rel), List.of(reviewer)).build()
        : JsonPatch.builder().add(JsonPointer.of("linkset", "0", rel, "-"), reviewer).build();
client.patchLinkset(doc.url(), patch, UpdateOptions.ifMatch(doc.etag().orElseThrow()));
const doc = await client.readLinkset(url);
const rel = "https://example.org/rel/reviewer";           // extension relation types are URIs
const reviewer = { href: "https://id.example/bob" };

// JsonPointer escapes "/" in the relation URI as "~1".
// "add" on an existing member replaces it, so append with "/-" when the relation exists.
const patch = doc.linkset.targets(rel).length > 0
  ? new JsonPatch().add(JsonPointer.from(["linkset", 0, rel, "-"]), reviewer)
  : new JsonPatch().add(JsonPointer.from(["linkset", 0, rel]), [reviewer]);

await client.patchLinkset(doc.url, patch, { ifMatch: doc.etag! });

    : JSONPatch().add(JSONPointer.from("linkset", "0", rel, "-"), reviewer)
_ = try await client.patchLinkset(doc.url, patch: patch, options: UpdateOptions(ifMatch: doc.etag))

Always send If-Match Several agents may edit the same metadata. Pass the linkset's ETag so a concurrent change produces 412 Precondition Failed instead of a silent overwrite.

Replacing a linkset

Servers may also accept PUT of a complete linkset, and advertise it in Allow. Check before you use it. Servers without PUT support answer 405 Method Not Allowed.

LinksetDocument doc = client.readLinkset(url);
if (doc.supportsPut()) {                              // Allow lists PUT
    Linkset updated = doc.linkset()                   // Linkset is immutable: add returns a copy
            .add(url.toString(), "license", URI.create("https://creativecommons.org/licenses/by/4.0/"));
    client.updateLinkset(doc.url(), updated, UpdateOptions.ifMatch(doc.etag().orElseThrow()));
}
const doc = await client.readLinkset(url);
if (doc.allow.includes("PUT")) {
  const linkset = doc.linkset.clone();
  linkset.add(url, "license", "https://creativecommons.org/licenses/by/4.0/");
  await client.updateLinkset(doc.url, linkset, { ifMatch: doc.etag! });
}
lws::LinksetDocument doc = client.read_linkset(url);
if (std::ranges::find(doc.allow, "PUT") != doc.allow.end()) {
    doc.linkset.add(url, "license", "https://creativecommons.org/licenses/by/4.0/");
    client.update_linkset(doc.url, doc.linkset, {.if_match = doc.etag});
}
let mut doc = client.read_linkset(url).await?;
if doc.allow.iter().any(|m| m == "PUT") {
    doc.linkset.add(url.as_str(), "license", "https://creativecommons.org/licenses/by/4.0/", None);
    client
        .update_linkset(&doc.url, &doc.linkset)
        .if_match(doc.etag.as_deref().unwrap_or("*"))
        .await?;
}
doc, err := client.ReadLinkset(ctx, url)
if err != nil {
	return err
}
if slices.Contains(doc.Allow, "PUT") {
	doc.Linkset.Add(url, "license", "https://creativecommons.org/licenses/by/4.0/", nil)
	_, err = client.UpdateLinkset(ctx, doc.URL, doc.Linkset, lws.IfMatch(doc.ETag))
}
return err
doc = client.read_linkset(url)
if "PUT" in doc.allow:
    linkset = doc.linkset.copy()
    linkset.add(url, "license", "https://creativecommons.org/licenses/by/4.0/")
    client.update_linkset(doc.url, linkset, if_match=doc.etag)
LinksetDocument doc = await client.ReadLinksetAsync(url);
if (doc.SupportsPut)                                   // Allow lists PUT
{
    Linkset updated = doc.Linkset                      // Linkset is immutable: Add returns a copy
        .Add(url.AbsoluteUri, "license", "https://creativecommons.org/licenses/by/4.0/");
    await client.UpdateLinksetAsync(doc.Url, updated, new UpdateOptions { IfMatch = doc.ETag });
}

    let updated = doc.linkset                        // Linkset is a value: adding returns a copy
        .adding(anchor: url.absoluteString, rel: "license", href: "https://creativecommons.org/licenses/by/4.0/")
    _ = try await client.updateLinkset(doc.url, linkset: updated, options: UpdateOptions(ifMatch: doc.etag))
}

Content and links together

To change a resource's content and its links in one atomic request, pass links with setLinkset to update or patch. See Replace (PUT). Server-managed relations such as up, linkset and the LWS type are never overridden by client-supplied links.
