GO Go

github.com/ebremer/lws-client/go Go 1.23+ package lws zero third-party dependencies

A single package built on net/http, encoding/json and the standard crypto libraries. Every network call takes a context.Context, pagination uses range-over-func iterators, and errors work with errors.Is and errors.As.

Install

go get github.com/ebremer/lws-client/go@latest

# then: import lws "github.com/ebremer/lws-client/go"

First program

package main

import (
	"context"
	"fmt"
	"log"
	"strings"

	lws "github.com/ebremer/lws-client/go"
)

func main() {
	ctx := context.Background()
	key, err := lws.GenerateP256Key()
	if err != nil {
		log.Fatal(err)
	}
	credentials, err := lws.NewDIDKeyCredentials(key, nil)
	if err != nil {
		log.Fatal(err)
	}
	client := lws.NewClient(lws.WithAuthenticator(lws.NewTokenExchangeAuthenticator(credentials, nil)))
	fmt.Println("agent:  ", credentials.Agent())

	storage, err := client.DiscoverStorage(ctx, "http://localhost:8787/root/")
	if err != nil {
		log.Fatal(err)
	}
	root, err := storage.StorageRoot()
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("storage:", storage.ID, " root:", root)

	folder, err := client.CreateContainer(ctx, root, lws.Slug("hello-world"))
	if err != nil {
		log.Fatal(err)
	}
	file, err := client.Create(ctx, folder.Location, strings.NewReader("Hello, LWS!"), "text/plain", lws.Slug("hello.txt"))
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("created:", file.Location)

	res, err := client.Read(ctx, file.Location)
	if err != nil {
		log.Fatal(err)
	}
	fmt.Printf("%s  (etag %s, parent %s)\n", res.Text(), res.ETag, res.Parent)
}

Configure the client

client := lws.NewClient(
	lws.WithAuthenticator(lws.NewTokenExchangeAuthenticator(credentials, nil)),
	lws.WithUserAgent("my-app/1.0"),         // default "lws-client-go/0.1.0"
	lws.WithHeader("Accept-Language", "en"), // added to every request
	lws.WithTimeout(20*time.Second),
	// lws.WithHTTPClient(myHTTPClient),     // bring your own *http.Client (transport, proxies)
)

// Every call takes a context (deadlines, cancellation) plus per-call options.
ctx, cancel := context.WithTimeout(ctx, 5*time.Second)
defer cancel()
page, err := client.ReadContainer(ctx, container, lws.Header("X-Trace", "1"))
if err != nil {
	return err
}
fmt.Println(page.TotalItems)

Go idioms

AspectHow the Go client does it
CallsBlocking methods with ctx context.Context first; the *lws.Client is safe for concurrent use and shares one in-flight token exchange
Paginationiter.Seq2[T, error]: for item, err := range client.ListContainer(ctx, url); ListContainerPages yields whole pages
OptionsClient options WithHTTPClient, WithAuthenticator, WithUserAgent, WithHeader, WithTimeout; per-call options Slug, Types, Links, IfMatch, IfNoneMatch, IfModifiedSince, Accept, ByteRange, Prefer, SetLinkset, Recursive, Header
BodiesAny io.Reader; CreateJSON marshals values; ReadStream returns an io.ReadCloser
Absent valuesZero values and sentinels: TotalItems/Size are -1 when missing; times are time.Time (zero if absent) plus the raw string
Errors*HTTPError (StatusCode, Problem, Header, Challenges) matching sentinels ErrNotFound, ErrConflict, ErrPreconditionFailed…; *AuthenticationError, *ProtocolError, *SignatureVerificationError
Webhooksverifier.Handler(inbox, fn) is an http.Handler; VerifyRequest(r, inbox) for custom handlers

Notes and deviations

  • Per-call options are one variadic CallOption type shared by all methods. Each method documents which options it honours.
  • SubscribeWebhook(ctx, storage, req) checks subscriptionType before subscribing. Subscribe takes a raw service URL.
  • Redirects: the client wraps CheckRedirect to drop Authorization and re-authorize per realm. Plain Go would forward the header to the same host on a different port.
  • Streaming upload bodies trigger a HEAD to obtain a token first. Self-signed credentials refresh 60 s before expiry, or at half the lifetime for short lifetimes.
  • Extras: ReadStream, PatchRaw, ReadLinksetAt, ListContainerPages, SearchPage, ContentDigest, and JWT/did:key decoding helpers.
