SW Swift

lws-client 0.1.0 (SwiftPM) Swift 6, strict concurrency module LWS 1 dependency: swift-crypto (CryptoKit)

A Swift client for Apple platforms and Linux, built on URLSession. Every operation is async throws and honours task cancellation, listings are lazy AsyncSequences for for try await, options and models are Sendable value types, and errors are one LWSError enum to match with catch LWSError.notFound.

Install

# Package.swift: the package is the repository itself (its Package.swift is at the root)
#   dependencies: [.package(url: "https://github.com/ebremer/lws-client.git", from: "0.1.0")]
#   target dependencies: [.product(name: "LWS", package: "lws-client")]
# Xcode: File > Add Package Dependencies…, https://github.com/ebremer/lws-client.git, product "LWS"

# Swift 6.0+; macOS 13, iOS 16, tvOS 16, watchOS 9, visionOS 1, or Linux.
# One dependency: swift-crypto (CryptoKit on Apple platforms), for ES256 and Ed25519.

The package's manifest is the repository's root Package.swift (SwiftPM takes packages from a git repository only there); the sources are in swift/.

First program

import Foundation
import LWS

let credentials = try SelfSignedCredentials.didKey(.generateP256())
let client = LWSClient(authenticator: TokenExchangeAuthenticator(credentials: credentials))
print("agent:   \(credentials.agent)")

let storage = try await client.discoverStorage(URL(string: "http://localhost:8787/root/")!)
print("storage: \(storage.id)  root: \(try storage.storageRoot())")

let folder = try await client.createContainer(in: try storage.storageRoot(), options: CreateOptions(slug: "hello-world"))
let file = try await client.createText(in: folder.location, text: "Hello, LWS!", options: CreateOptions(slug: "hello.txt"))
print("created: \(file.location)")

let resource = try await client.read(file.location)
print("\(resource.text)  (etag \(resource.etag ?? "-"), parent \(resource.metadata.parent?.absoluteString ?? "-"))")

This is a complete main.swift: add it to an executable target that depends on the LWS product, and swift run it.

Configure the client

let client = LWSClient(options: LWSClientOptions(
    authenticator: TokenExchangeAuthenticator(credentials: credentials),
    userAgent: "my-app/1.0",                         // default "lws-client-swift/0.1.0"
    defaultHeaders: ["Accept-Language": "en"],       // added to every request
    timeout: 20,                                     // seconds, per request (each redirect hop)
    maxRedirects: 5                                  // followed by the client itself (default 10)
    // transport: myTransport,                       // any HTTPTransport (default: URLSessionTransport)
))

// Per-call headers and time limits; every operation honours task cancellation.
let page = try await client.readContainer(container, options: RequestOptions(headers: ["X-Trace": "1"], timeout: 5))
print(page.totalItems ?? 0)

// Another identity over the same transport:
let anonymous = client.withAuthenticator(nil)

LWSClient is an immutable, Sendable class: create one and share it between tasks. withAuthenticator(a) returns a client with a different authenticator over the same transport. The client follows redirects itself and authorizes each hop afresh, so its HTTPTransport must not follow redirects. The default URLSessionTransport owns a private URLSession whose delegate refuses them, with cookies and caching off; a transport of your own (an AsyncHTTPClient adapter, a test double) implements one method, send(_ request: HTTPRequest) async throws -> HTTPResponse.

Swift idioms

AspectHow the Swift client does it
CallsEvery operation is async throws. Cancelling the task throws CancellationError; a timeout (the timeout option, a hard limit per request) throws LWSError.transport with isTimeout
PaginationlistContainer, listTypes, searchAll, listSubscriptions… return a lazy PagedSequence (an AsyncSequence): for try await item in …, where clauses, or collect(). Pages are fetched as the iteration advances
OptionsValue types with defaulted initializers: CreateOptions(slug: …), UpdateOptions(ifMatch: etag), DeleteOptions(recursive: true), ReadOptions(range: .bytes(0...1023)). Every one also has headers and timeout
BodiesData in and out, always replayable; createText, createJSON(json:) and createJSON(value:) for any Encodable; Resource.text, .json() and .decode(_:) for any Decodable
JSONJSONValue, an enum with literals (["name": "Alice", "age": 30]), and JSONObject, which keeps member order so that documents (linksets, access documents, raw) round-trip unchanged
ModelsSendable structs; absent values are optionals; URLs are URL, absolute in every result
ErrorsOne enum LWSError: Error: a case per status (.notFound, .conflict, .preconditionFailed, … each with its HTTPError), .http for other statuses, .authentication, .protocolError, .signatureVerification, .transport, .invalidArgument. status and httpError help across cases
ConcurrencySwift 6 language mode with strict concurrency checking. TokenExchangeAuthenticator, SelfSignedCredentials and WebhookVerifier are actors: concurrent requests share one in-flight token exchange
Cryptoswift-crypto, which is CryptoKit on Apple platforms and BoringSSL elsewhere: P-256, P-384 and Ed25519 keys and signatures, SHA-256 and SHA-512

Notes and deviations

  • Names follow the Swift API Design Guidelines: acronyms are upper case (LWSClient, JSONPatch, DIDKey, linksetURL), and creation takes the container as a label: create(in:body:contentType:), createContainer(in:).
  • The contract's error classes are the cases of LWSError; its ProtocolError is .protocolError, and an argument that is not an absolute http(s) URL is .invalidArgument, thrown before any request.
  • Request and response bodies are Data: there is no streaming read or upload. Every body can therefore be replayed for the single retry after a 401.
  • storageRoot() is a throwing method, because a description without a StorageRoot service is a protocol error. The other well-known services are optional properties (notificationService, typeSearchService…).
  • TypeQuery's builders throw .invalidArgument for an IRI that is not absolute or an empty OR group, so a query is written try TypeQuery().anyOf(…).allOf(…). Linkset, JSONPatch and TypeQuery are values: adding, removing, add, replace… return copies.
  • WebhookVerifier.verify(method:url:headers:body:) takes the parts of the request, so any server (Vapor, Hummingbird, SwiftNIO…) can host the inbox: pass the inbox URL as registered, not the one a proxy forwarded to.
  • On Linux, URLSession comes from FoundationNetworking, over libcurl. A per-task delegate is ignored there, so the default transport refuses redirects with a session delegate, and an authorization server response from another URL than the one requested is refused as a followed redirect.
  • Extras: request(_:_:body:contentType:) sends any method through the authentication and redirect pipeline; readLinksetResource(_:) reads a linkset at a known URL.
