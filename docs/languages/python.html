PY Python

lws-client 0.1.0 Python 3.10+ httpx · optional cryptography fully typed (py.typed, mypy --strict)

LwsClient (synchronous) and AsyncLwsClient (asyncio) share a sans-I/O core. Every operation, redirect rule and step of the token exchange is written once, so the two clients behave identically.

Install

# From PyPI (once published)
pip install "lws-client[crypto]"

# From GitHub today
pip install "lws-client[crypto] @ git+https://github.com/ebremer/lws-client#subdirectory=python"

# The crypto extra (cryptography) enables self-signed identities and webhook verification.

First program

from lws_client import LwsClient, SelfSignedCredentials, SigningKey, TokenExchangeAuthenticator

credentials = SelfSignedCredentials.did_key(SigningKey.generate("ES256"))
print("agent:  ", credentials.agent)

with LwsClient(authenticator=TokenExchangeAuthenticator(credentials)) as client:
    storage = client.discover_storage("http://localhost:8787/root/")
    print("storage:", storage.id, " root:", storage.storage_root())

    folder = client.create_container(storage.storage_root(), slug="hello-world")
    file = client.create_text(folder.location, "Hello, LWS!", slug="hello.txt")
    print("created:", file.location)

    resource = client.read(file.location)
    print(resource.text, f" (etag {resource.etag}, parent {resource.parent})")

Configure the client

credentials = SelfSignedCredentials.did_key(SigningKey.generate())
client = LwsClient(
    authenticator=TokenExchangeAuthenticator(credentials),
    user_agent="my-app/1.0",                    # default "lws-client-python/0.1.0"
    default_headers={"Accept-Language": "en"},  # added to every request
    timeout=20.0,
    # http_client=httpx.Client(...),            # bring your own (proxies, HTTP/2, mounts)
)
with client:                                    # closes the underlying httpx client
    page = client.read_container(container, headers={"X-Trace": "1"})   # per-call headers
    print(page.total_items)

Async usage

import asyncio

from lws_client import AsyncLwsClient, SelfSignedCredentials, SigningKey, TokenExchangeAuthenticator


async def main() -> None:
    credentials = SelfSignedCredentials.did_key(SigningKey.generate())
    async with AsyncLwsClient(authenticator=TokenExchangeAuthenticator(credentials)) as client:
        storage = await client.discover_storage("http://localhost:8787/root/")
        root = storage.storage_root()
        # Concurrent requests share a single token exchange.
        pages = await asyncio.gather(*(client.read_container(root) for _ in range(5)))
        print([page.total_items for page in pages])
        async for item in client.list_container(root):
            print(item.id)


asyncio.run(main())

Python idioms

AspectHow the Python client does it
CallsLwsClient and AsyncLwsClient with identical method names; both are context managers that close their httpx client
PaginationGenerators: list_container, list_types, search_all…; async generators on AsyncLwsClient; container_pages / search_pages yield whole pages
OptionsKeyword arguments: slug=, types=, links=, if_match=, if_none_match=, range=(start, end), recursive=, set_linkset=
Bodiesbytes, str or an iterable of bytes; create_json, create_text, read_json; stream(url) for unbuffered reads
ModelsFrozen, slotted dataclasses; is_container/is_data_resource/not_modified are properties; datetimes are aware datetimes plus raw strings
ErrorsLwsError → HttpError (status, problem, headers, body_text) → NotFoundError, …; TransportError wraps httpx failures
CryptoThe [crypto] extra (cryptography) is imported lazily, with a clear error if it is missing; ES256, EdDSA and ES384

Modules

Everything is importable from the package root (from lws_client import …). Submodules: client, models, linkset, auth, crypto, webhook, notifications, access, type_index, json_patch, headers, structured_fields, errors and constants.

Notes and deviations

  • NotImplementedByServerError (501) avoids shadowing the built-in NotImplementedError. GoneError subclasses NotFoundError, since expired page links may answer either status.
  • links_for(rel) and find_services(type) are the lookups, because links and services are fields.
  • subscribe(service, topics, inbox, expires=…) takes arguments rather than a request object.
  • Invalid builder input raises ValueError. A malformed notification body during webhook verification raises SignatureVerificationError, so a handler only needs to catch one exception type.
  • Redirects are followed manually, for GET/HEAD/OPTIONS/QUERY only, with credentials re-evaluated per hop.
  • Extras: authenticate(url) to obtain a token up front, stream, read_linkset_at, ES384, verify_jwt and did_key_to_jwk.
