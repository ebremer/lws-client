Ebremer.Lws.Client 0.1.0 .NET 10 namespace Ebremer.Lws 1 dependency: BouncyCastle (Ed25519)

A .NET client built on HttpClient and System.Text.Json. Every operation is async and takes a CancellationToken, listings are lazy IAsyncEnumerable<T>s for await foreach, options are init-only records, and nullable reference types mark every value that may be absent.

Install

# From NuGet (once published)
dotnet add package Ebremer.Lws.Client --version 0.1.0

# Until then: clone the repository and reference the project from yours
git clone https://github.com/ebremer/lws-client.git
dotnet add reference lws-client/csharp/src/Ebremer.Lws.Client/Ebremer.Lws.Client.csproj

# Targets .NET 10 (net10.0). One dependency: BouncyCastle.Cryptography, for Ed25519.

First program

using Ebremer.Lws;
using Ebremer.Lws.Auth;

var credentials = SelfSignedCredentials.DidKey(SigningKey.GenerateP256());
using var authenticator = new TokenExchangeAuthenticator(credentials);
using var client = new LwsClient(new LwsClientOptions { Authenticator = authenticator });
Console.WriteLine($"agent:   {credentials.Agent}");

StorageDescription storage = await client.DiscoverStorageAsync(new Uri("http://localhost:8787/root/"));
Console.WriteLine($"storage: {storage.Id}  root: {storage.GetStorageRoot()}");

CreateResult folder = await client.CreateContainerAsync(storage.GetStorageRoot(), new CreateOptions { Slug = "hello-world" });
CreateResult file = await client.CreateTextAsync(folder.Location, "Hello, LWS!", options: new CreateOptions { Slug = "hello.txt" });
Console.WriteLine($"created: {file.Location}");

Resource resource = await client.ReadAsync(file.Location);
Console.WriteLine($"{resource.GetText()}  (etag {resource.ETag ?? "-"}, parent {resource.Metadata.Parent})");

This is a complete Program.cs with top-level statements: create a console project (dotnet new console), add the package or project reference, and run it with dotnet run.

Configure the client

using var authenticator = new TokenExchangeAuthenticator(credentials);
using var client = new LwsClient(new LwsClientOptions
{
    Authenticator = authenticator,
    UserAgent = "my-app/1.0",                                       // default "lws-client-csharp/0.1.0"
    DefaultHeaders = new Dictionary<string, string> { ["Accept-Language"] = "en" },   // added to every request
    Timeout = TimeSpan.FromSeconds(20),                             // per request (each redirect hop)
    MaxRedirects = 5,                                               // followed by the client itself (default 10)
    // HttpClient = myHttpClient,                                   // bring your own (with AllowAutoRedirect = false)
});

// Per-call headers and timeouts; every operation also takes a CancellationToken.
using var cts = new CancellationTokenSource(TimeSpan.FromSeconds(30));
ContainerPage page = await client.ReadContainerAsync(container, new RequestOptions
{
    Headers = new Dictionary<string, string> { ["X-Trace"] = "1" },
    Timeout = TimeSpan.FromSeconds(5),
}, cts.Token);
Console.WriteLine(page.TotalItems);

// Another identity over the same connections:
using LwsClient anonymous = client.WithAuthenticator(null);

LwsClient is immutable and thread-safe: create one, share it, and dispose it when you are done. It owns its HttpClient unless you pass one in. WithAuthenticator(a) returns a client with a different authenticator that shares the same connections. The client follows redirects itself and re-checks credentials on each hop, so an HttpClient or HttpMessageHandler you supply must not follow redirects (AllowAutoRedirect = false). One that does bypasses that protection.

C# idioms

AspectHow the C# client does it
CallsEvery operation is an …Async method returning a Task, with an optional trailing CancellationToken. Cancelling throws OperationCanceledException; a timeout throws LwsTransportException
PaginationListContainerAsync, ListTypesAsync, SearchAllAsync, ListSubscriptionsAsync… return lazy IAsyncEnumerable<T>s: await foreach, or .NET 10's System.Linq.AsyncEnumerable operators (Where, Select, ToListAsync)
OptionsRecords with init properties, set with object initializers: new CreateOptions { Slug = … }, new UpdateOptions { IfMatch = etag }, new DeleteOptions { Recursive = true }, new ReadOptions { Range = new RangeHeaderValue(0, 1023) }. Every one also has Headers and Timeout
BodiesReadOnlyMemory<byte> (replayable) or a Stream (sent once, after a HEAD obtains a token); CreateTextAsync and CreateJsonAsync; ReadStreamAsync for unbuffered reads
ModelsImmutable classes and records. Absent values are null under nullable reference types; JSON is JsonElement / JsonObject; GetJson<T>() binds with System.Text.Json
ErrorsLwsException → HttpException (Status, Problem, Headers, Body) → NotFoundException, ConflictException, …; narrow them with catch … when
DisposalLwsClient, TokenExchangeAuthenticator, WebhookVerifier and ResourceStream are disposable: using var / await using
CryptoThe BCL's ECDsa (P-256, and P-384 for imported keys and webhook signatures) and SHA256/SHA512. Ed25519 comes from BouncyCastle.Cryptography, because .NET 10 has none

Notes and deviations

  • The 501 exception is HttpNotImplementedException, so that using Ebremer.Lws; never clashes with System.NotImplementedException. The contract's HttpError is HttpException, ProtocolError is ProtocolException, and transport failures are LwsTransportException (its InnerException is the HttpRequestException, IOException or TimeoutException). An argument that is not an absolute http(s) URL throws ArgumentException.
  • A subscription's URL is Subscription.Url. SubscribeAsync(Service, …) checks the service's subscriptionType; SubscribeAsync(Uri, …) takes a raw endpoint.
  • StorageDescription.GetStorageRoot() is a method because it throws ProtocolException when there is no StorageRoot service. The other well-known services are nullable properties (NotificationService, TypeSearchService…).
  • ContainerPage.Id is never null: a search page without an id takes the page URL.
  • Linkset, JsonPatch and TypeQuery are immutable, so Add, Remove, Replace, AllOf… return new instances. Start a query from new TypeQuery().
  • ReadLinksetResourceAsync(linksetUrl) complements ReadLinksetAsync(resourceUrl) when you already know the linkset URL.
  • WebhookVerifier.VerifyAsync(HttpListenerRequest, inbox) serves System.Net.HttpListener. ASP.NET Core and other frameworks pass the method, the registered inbox URL, HeaderMap.From(…) and the body bytes.
  • CreateJsonAsync<T> and GetJson<T> use reflection-based serialization. For trimming and native AOT, CreateJsonAsync has a JsonTypeInfo<T> overload.
  • Extras: RequestAsync(method, url, …) sends any request through the authentication and redirect pipeline; ReadStreamAsync, SigningKey.FromECDsa (P-256 or P-384) and Jwt helpers.
