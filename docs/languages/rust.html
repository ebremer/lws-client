RS Rust

lws-client 0.1.0 Rust 1.85+ (edition 2024) tokio · reqwest · RustCrypto #![forbid(unsafe_code)]

An async client built on reqwest. It uses request builders you can .await directly, futures::Stream pagination, serde-based models and one Error enum with convenience predicates. Client is Clone + Send + Sync.

Install

# Cargo.toml
[dependencies]
lws-client = { git = "https://github.com/ebremer/lws-client" }   # crates.io (once published): "0.1"
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }
futures-util = "0.3"   # TryStreamExt for the paginated streams

First program

use lws_client::{Client, SelfSignedCredentials, TokenExchangeAuthenticator, Url, crypto::SigningKey};

#[tokio::main]
async fn main() -> lws_client::Result<()> {
    let credentials = SelfSignedCredentials::did_key(SigningKey::generate_p256()?);
    println!("agent:   {}", credentials.agent());
    let client = Client::builder()
        .authenticator(TokenExchangeAuthenticator::new(credentials))
        .build()?;

    let storage = client.discover_storage("http://localhost:8787/root/").await?;
    let root = storage.storage_root()?.clone();
    println!("storage: {}  root: {root}", storage.id);

    let folder = client.create_container(&root).slug("hello-world").await?.location;
    let file = client
        .create(&folder, "Hello, LWS!", "text/plain")
        .slug("hello.txt")
        .await?
        .location;
    println!("created: {file}");

    let resource = client.read(&file).await?;
    let etag = resource.metadata.etag.as_deref().unwrap_or("-");
    let parent = resource.metadata.parent().map(Url::as_str).unwrap_or("-");
    println!("{}  (etag {etag}, parent {parent})", resource.text()?);
    Ok(())
}

Configure the client

let client = Client::builder()
    .authenticator(TokenExchangeAuthenticator::new(credentials))
    .user_agent("my-app/1.0")                    // default "lws-client-rust/0.1.0"
    .default_header("Accept-Language", "en")     // added to every request
    .timeout(Duration::from_secs(20))
    // .http_client(my_reqwest_client)           // bring your own reqwest::Client
    .build()?;

// Request builders take per-call headers; dropping the future cancels the request.
let resource = client.read(url).header("X-Trace", "1").await?;
println!("{}", resource.metadata.status);

Rust idioms

AspectHow the Rust client does it
Callsasync; operations with options return request builders (ReadRequest, CreateRequest, UpdateRequest, PatchRequest, DeleteRequest) that implement IntoFuture, so call .await directly or .send().await
PaginationLwsStream<T>, a futures::Stream of Result<T>: try_next, try_collect (bring futures_util::TryStreamExt)
URLs and bodiesAny impl IntoUrl (Url, &str, String); bodies impl Into<Body> (bytes, strings; Body::from_reqwest for streams)
ModelsPlain structs with public fields; datetimes as SystemTime plus the raw string
Errorslws_client::Error with one variant per status (each holding Box<HttpError>) and helpers status(), problem(), is_not_found(), is_conflict(), is_precondition_failed()…
ExtensibilityAuthenticator and CredentialProvider are object-safe traits returning BoxFutures (use Arc<dyn …>)

Notes and deviations

  • JsonPatch::move_value (move is a keyword) and Constraint::resource_type.
  • url::ParseError converts into Error::InvalidInput, so Url::parse(…)? works in functions returning lws_client::Result.
  • Resource::text() decodes UTF-8 only. title* link parameters are kept raw.
  • The webhook verifier supports P-256 and Ed25519.
  • The built-in HTTP client follows redirects itself (up to 5 hops) and re-authorizes on every hop, so a token is only sent to URLs inside its realm. If you pass your own reqwest::Client through http_client(), its redirect policy applies instead.
  • Streaming uploads need reqwest's stream feature in your crate (Body::from_reqwest). The client sends a HEAD first to obtain a token.
