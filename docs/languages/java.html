A modern Java client built on java.net.http.HttpClient. It offers blocking calls that pair well with virtual threads, CompletableFuture variants for the core operations, records for every model, lazy Streams for pagination, and JDK-only cryptography.

Install

# Until it is on Maven Central: build and install into your local repository (~/.m2)
git clone https://github.com/ebremer/lws-client.git
cd lws-client/java && mvn install

First program

import com.ebremer.lws.Body;
import com.ebremer.lws.CreateOptions;
import com.ebremer.lws.LwsClient;
import com.ebremer.lws.Resource;
import com.ebremer.lws.StorageDescription;
import com.ebremer.lws.auth.KeyPairs;
import com.ebremer.lws.auth.SelfSignedCredentials;
import com.ebremer.lws.auth.TokenExchangeAuthenticator;
import java.net.URI;

public class HelloLws {
    public static void main(String[] args) {
        SelfSignedCredentials credentials = SelfSignedCredentials.didKey(KeyPairs.generateP256());
        LwsClient client = LwsClient.builder()
                .authenticator(TokenExchangeAuthenticator.of(credentials))
                .build();
        System.out.println("agent:   " + credentials.agent());

        StorageDescription storage = client.discoverStorage(URI.create("http://localhost:8787/root/"));
        System.out.println("storage: " + storage.id() + "  root: " + storage.storageRoot());

        URI folder = client.createContainer(storage.storageRoot(), CreateOptions.slug("hello-world")).location();
        URI file = client.create(folder, Body.of("Hello, LWS!"), "text/plain", CreateOptions.slug("hello.txt")).location();
        System.out.println("created: " + file);

        Resource resource = client.read(file);
        System.out.println(resource.text() + "  (etag " + resource.etag().orElse("-")
                + ", parent " + resource.metadata().parent().orElse(null) + ")");
    }
}

Configure the client

LwsClient client = LwsClient.builder()
        .authenticator(TokenExchangeAuthenticator.of(credentials))
        .userAgent("my-app/1.0")                  // default "lws-client-java/0.1.0"
        .header("Accept-Language", "en")          // added to every request
        .timeout(Duration.ofSeconds(20))          // per request
        .connectTimeout(Duration.ofSeconds(5))
        // .httpClient(myHttpClient)              // bring your own java.net.http.HttpClient
        .build();

// Per-call headers and timeouts
ContainerPage page = client.readContainer(container,
        ReadOptions.builder().header("X-Trace", "1").timeout(Duration.ofSeconds(5)).build());
System.out.println(page.totalItems());

// Core operations have CompletableFuture variants
client.readAsync(url).thenAccept(resource -> System.out.println(resource.text()));

LwsClient is immutable and thread-safe; build one and share it. withAuthenticator(a) returns a copy with a different authenticator. The default HttpClient does not follow redirects itself. The client follows them instead and re-checks credentials on each hop. If you supply your own HttpClient with redirects enabled, you bypass that protection.

Java idioms

AspectHow the Java client does it
CallsBlocking methods (ideal with virtual threads) plus headAsync, readAsync, readContainerAsync, createAsync, createContainerAsync, updateAsync, patchAsync, deleteAsync, discoverStorageAsync
PaginationlistContainer, listTypes, searchAll, listSubscriptions… return lazy Streams
OptionsImmutable option objects with builders and static shortcuts: CreateOptions.slug(…), UpdateOptions.ifMatch(…), DeleteOptions.recursive(), ReadOptions.ifNoneMatch(…)
BodiesBody.of(String | byte[]), Body.ofJson(Object), Body.ofFile(Path), Body.ofInputStream(Supplier); all replayable, so the 401 retry always works
ModelsRecords with Optional / OptionalLong for absent values; JSON as Jackson JsonNode; json(Class) for data binding
ErrorsUnchecked: LwsException → HttpStatusException → NotFoundException, ConflictException, …
CryptoJDK only: SHA256withECDSAinP1363Format, Ed25519; also RSA public JWKs and P-384/RSA webhook signatures

Notes and deviations

  • The contract's ProtocolError is LwsProtocolException (to avoid clashing with java.net.ProtocolException). HttpError is HttpStatusException, and transport failures are LwsTransportException.
  • Option getters are named ifMatchValue(), slugValue()… because the static factories use the plain names.
  • ContainerPage.id() is Optional because synthetic search pages have no id.
  • readLinksetResource(linksetUrl) complements readLinkset(resourceUrl) when you already know the linkset URL.
  • Linkset is immutable: add/remove return a new instance.
  • HttpExchangeWebhooks needs the jdk.httpserver module, which is declared requires static.
