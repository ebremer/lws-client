TS JavaScript / TypeScript

lws-client 0.1.0 ESM + .d.ts Node 20+ · browsers · Deno · Bun zero runtime dependencies

Written in strict TypeScript and compiled to ES modules. The library core only uses web platform APIs (fetch, WebCrypto, URL, streams), so the same package runs on servers, in browsers and on edge runtimes.

Install

# From npm (once published)
npm install lws-client

# From source today: build a tarball and install it into your project
git clone https://github.com/ebremer/lws-client.git
cd lws-client/js && npm install && npm run build && npm pack
npm install /path/to/lws-client/js/lws-client-0.1.0.tgz

First program

import { LwsClient, TokenExchangeAuthenticator, SelfSignedCredentials, generateKeyPair } from "lws-client";

const credentials = SelfSignedCredentials.didKey(await generateKeyPair("ES256"));
const client = new LwsClient({ authenticator: new TokenExchangeAuthenticator(credentials) });
console.log("agent:  ", credentials.agent);

const storage = await client.discoverStorage("http://localhost:8787/root/");
console.log("storage:", storage.id, " root:", storage.storageRoot());

const folder = await client.createContainer(storage.storageRoot(), { slug: "hello-world" });
const file = await client.createText(folder.location, "Hello, LWS!", { slug: "hello.txt" });
console.log("created:", file.location);

const resource = await client.read(file.location);
console.log(await resource.text(), ` (etag ${resource.etag}, parent ${resource.parent})`);

Configure the client

const credentials = SelfSignedCredentials.didKey(await generateKeyPair());
const client = new LwsClient({
  authenticator: new TokenExchangeAuthenticator(credentials),
  userAgent: "my-app/1.0",               // default "lws-client-js/0.1.0" (not sent by browsers)
  headers: { "Accept-Language": "en" },  // added to every request
  timeoutMs: 20_000,
  // fetch: myFetch,                     // inject your own fetch (proxies, tests, instrumentation)
});

// Every operation also takes { headers, signal } for per-call headers and cancellation.
const controller = new AbortController();
const page = await client.readContainer(container, { signal: controller.signal });
console.log(page.totalItems);

TypeScript idioms

AspectHow the JS/TS client does it
Callsasync methods returning Promises; every operation accepts { headers, signal } for cancellation with AbortSignal
PaginationAsyncGenerators: for await (const item of client.listContainer(url))
OptionsPlain option objects ({ slug, types, links }, { ifMatch }, { recursive })
BodiesAny BodyInit: string, Uint8Array, Blob, ReadableStream; createJson, createText, updateJson helpers
ResponsesResource exposes text(), json(), bytes() and blob() (buffered once, re-readable), plus the raw body stream
ErrorsError subclasses: LwsError → HttpError (with status, problem, headers) → NotFoundError, …
Escape hatchclient.fetch(url, init) sends any request through the authenticator without throwing on error statuses

Runtimes and entry points

Entry pointUse
lws-clientEverything: client, models, auth, crypto, webhook verification. No node: imports
lws-client/nodeNode helpers: createWebhookHandler, webhookRequestFromIncomingMessage, readBody
  • Browsers: calls to another origin need CORS on the storage and authorization server. The default User-Agent is not set in browsers, to avoid extra preflights. See examples/browser.html.
  • Custom fetch: pass { fetch } to add proxies, retries or instrumentation, or to test without a network.
  • Ed25519 needs a WebCrypto implementation with Ed25519 support: Node 22+ and current browsers have it.

Notes and deviations

  • links(rel?), services(type?) and capabilities(type?) are methods, not fields.
  • The Linkset model keeps anchors and hrefs exactly as received, so a read-modify-write round trip is lossless.
  • WebhookVerifier takes a resolveStorageDescription callback (usually (id) => client.getStorageDescription(id)) rather than a client.
  • Invalid builder input such as a relative IRI in a TypeQuery throws TypeError.
  • Streaming upload bodies trigger a HEAD to obtain a token first, because streams cannot be replayed.
