PHP PHP

lws-client 0.1.0 (Composer) PHP 8.2+ namespace Ebremer\Lws no Composer dependencies (ext-curl, ext-openssl, ext-sodium; PSR-18 optional)

A PHP client for any PHP 8.2+ application, from a plain script to a framework. Calls are synchronous, options are named arguments (slug:, ifMatch:, recursive:), listings are lazy PagedSequences for foreach, models are final classes with readonly properties, and errors are one exception hierarchy under LwsException. It needs only the extensions most PHP builds bundle.

Install

# From Packagist (once published)
composer require ebremer/lws-client

# From GitHub today: the package is the repository itself (its composer.json is at the root)
composer config repositories.lws-client vcs https://github.com/ebremer/lws-client
composer require ebremer/lws-client:dev-main

# PHP 8.2+ with ext-curl, ext-openssl and ext-sodium (bundled with most PHP builds). No Composer
# dependencies; psr/http-client is optional (Psr18Transport, for Guzzle, Symfony HttpClient, …).

The package's manifest is the repository's root composer.json (Packagist and Composer's VCS repositories read the manifest only there); the sources are in php/src, autoloaded as Ebremer\Lws\ (PSR-4).

First program

<?php
require __DIR__ . '/vendor/autoload.php';

use Ebremer\Lws\Auth\SelfSignedCredentials;
use Ebremer\Lws\Auth\SigningKey;
use Ebremer\Lws\Auth\TokenExchangeAuthenticator;
use Ebremer\Lws\LwsClient;

$credentials = SelfSignedCredentials::didKey(SigningKey::generateP256());
$client = new LwsClient(authenticator: new TokenExchangeAuthenticator($credentials));
echo "agent:   {$credentials->agent}\n";

$storage = $client->discoverStorage('http://localhost:8787/root/');
echo "storage: {$storage->id}  root: {$storage->storageRoot()}\n";

$folder = $client->createContainer($storage->storageRoot(), slug: 'hello-world');
$file = $client->createText($folder->location, 'Hello, LWS!', slug: 'hello.txt');
echo "created: {$file->location}\n";

$resource = $client->read($file->location);
printf("%s  (etag %s, parent %s)\n", $resource->text(), $resource->etag ?? '-', $resource->metadata->parent ?? '-');

This is a complete script: save it next to your project's vendor/ directory and run it with php.

Configure the client

$client = new LwsClient(
    authenticator: new TokenExchangeAuthenticator($credentials),
    userAgent: 'my-app/1.0',                         // default "lws-client-php/0.1.0"
    defaultHeaders: ['Accept-Language' => 'en'],     // added to every request
    timeout: 20,                                     // seconds, per request (each redirect hop)
    maxRedirects: 5,                                 // followed by the client itself (default 10)
    // transport: $myTransport,                      // any HttpTransport (default: CurlTransport)
);

// Per-call headers and time limits, as named arguments of every operation.
$page = $client->readContainer($container, headers: ['X-Trace' => '1'], timeout: 5);
echo $page->totalItems ?? 0, "\n";

// Another identity over the same transport:
$anonymous = $client->withAuthenticator(null);

LwsClient is immutable: create one and pass it around. withAuthenticator($a) returns a client with a different authenticator over the same transport. The client follows redirects itself and authorizes each hop afresh, so its HttpTransport must not follow redirects. The default CurlTransport keeps one curl handle (so connections are reused), follows no redirects, stores no cookies and speaks http and https only; its constructor takes extra CURLOPT_* options (a CA bundle, a proxy). Psr18Transport runs the client on any PSR-18 client (Guzzle, Symfony HttpClient's Psr18Client, …) with PSR-17 factories; that client must not follow redirects either. A transport of your own implements one method, send(HttpRequest $request): HttpResponse.

PHP idioms

AspectHow the PHP client does it
CallsSynchronous, like PHP itself. The timeout option (seconds, per request) bounds each exchange; running out of time throws TransportException, whose isTimeout() is true
OptionsPHP 8 named arguments on every operation: create($c, $body, 'text/plain', slug: 'a.txt', types: […]), update($url, $body, $type, ifMatch: $etag), delete($url, recursive: true), read($url, range: ByteRange::of(0, 1023)). Every operation also takes headers: and timeout:
PaginationlistContainer, listTypes, searchAll, listSubscriptions… return a lazy PagedSequence (an IteratorAggregate): foreach, toArray() or take($n). Pages are fetched as the iteration advances, and each foreach starts again from the first page
BodiesPHP strings, which are bytes: always replayable for the retry after a 401. createText and createJson($c, $value) for any value json_encode() takes; ReadResult::text() (by the response charset) and json()
JSONJson::decode() turns objects into associative arrays, except {} and objects with keys "0", "1"…, which stay \stdClass, so documents (linksets, access documents, raw) round-trip unchanged. Write new \stdClass() for {} in values you send
ModelsFinal classes with public readonly properties ($meta->etag, $page->items); computed values are methods (storageRoot(), isContainer()). URLs are strings, absolute in every result
ErrorsLwsException (a RuntimeException): HttpException with a subclass per status (NotFoundException, ConflictException, PreconditionFailedException, …), AuthenticationException, ProtocolException, SignatureVerificationException, TransportException. Caller mistakes are PHP's own \InvalidArgumentException, thrown before any request
Cryptoext-openssl for P-256 and P-384 ECDSA (JOSE's raw r‖s, converted from OpenSSL's DER), ext-sodium for Ed25519, hash() for SHA-256 and SHA-512
SecretsKeys, tokens and credentials are hidden from var_dump and print_r (__debugInfo), and marked #[\SensitiveParameter] so stack traces leave them out

Notes and deviations

  • The contract's Resource is ReadResult, because resource is a soft-reserved word in PHP. Link::typeLink($iri) builds a rel="type" link, since type() is the accessor of the type attribute. A subscription's URL (the contract's subscription) is Subscription::$url.
  • The contract's error classes are exception classes named …Exception (NotFoundException, ProtocolException); the 501 one is NotImplementedException, which clashes with nothing in PHP.
  • Request and response bodies are strings: there is no streaming read or upload, so every body can be replayed for the single retry after a 401. Read large resources in pieces with range:.
  • JsonPatch, TypeQuery and Linkset are fluent builders that change in place: $doc->linkset->add(…), then updateLinkset($doc->url, $doc->linkset). TypeQuery's builders throw \InvalidArgumentException for an IRI that is not absolute or an empty OR group.
  • WebhookVerifier::verifyGlobals($inboxUrl) verifies the delivery of the current request ($_SERVER and php://input), so a plain PHP script can be the inbox; verifyServerRequest($request, $inboxUrl) takes a PSR-7 request, and verify($method, $url, $headers, $body) the parts. Pass the inbox URL as registered, not the one a proxy forwarded to.
  • The token cache lives in the TokenExchangeAuthenticator, so it lasts as long as the PHP process: one request under PHP-FPM, or the whole run of a CLI worker.
  • Extras: request($method, $url, body:, contentType:) sends any method through the authentication and redirect pipeline; readLinksetResource($url) reads a linkset at a known URL.
