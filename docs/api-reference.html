API cross-reference

All nine clients implement one API contract. This page maps each concept to its name in every language. Arguments are abbreviated: url is a URL (Java URI, C# Uri, Swift URL, Rust impl IntoUrl, otherwise a string). Go methods also take a leading ctx, Rust request builders are awaited, and C# methods are awaited and take an optional trailing CancellationToken. Swift methods are try awaited, and listings are for try awaited. PHP options are named arguments (slug:, ifMatch:) and listings are foreached.

Where names differ Keywords and built-ins force a few renames. C++ uses remove (not delete) and Constraint::op. Rust uses JsonPatch::move_value and Constraint::resource_type. Python uses NotImplementedByServerError, links_for and find_services. Java uses LwsProtocolException and HttpStatusException. C# uses HttpNotImplementedException, Subscription.Url and GetStorageRoot(). Swift uses LWSError.protocolError, upper-case acronyms (LWSClient, JSONPatch, DIDKey, linksetURL) and the label in: for the container of a create. PHP uses ReadResult for the contract's Resource (resource is soft-reserved), …Exception class names, Link::typeLink() and Subscription::$url. Each language guide lists its deviations.
