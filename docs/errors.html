Errors

Each client maps HTTP statuses to typed errors that line up with the LWS abstract responses (not permitted, unknown requester, target not found, conflict, …). It also attaches the request, the response headers and any RFC 9457 problem details.

All errors share a root: LwsException (Java, where it is unchecked, C#, and PHP, where it is a RuntimeException), LwsError (TypeScript, Python), lws::Error : std::runtime_error (C++), or a single enum (Rust's Error, Swift's LWSError, whose cases carry the HTTPError). Go uses *HTTPError plus sentinels that work with errors.Is and errors.As. Invalid builder input (a relative IRI in a type query, an access policy without actions) raises the language's ordinary argument error instead: IllegalArgumentException, TypeError, std::invalid_argument, ValueError, ArgumentException, a returned error, Rust's Error::InvalidInput, Swift's LWSError.invalidArgument, or PHP's \InvalidArgumentException.

Handling errors

try {
    client.read(url);
} catch (NotFoundException e) {
    System.out.println("no such resource");
} catch (UnauthorizedException e) {
    System.out.println("not authenticated " + e.challenges());
} catch (HttpStatusException e) {
    System.out.println(e.status() + " " + e.problem().flatMap(ProblemDetails::title).orElse(e.getMessage()));
} catch (AuthenticationException e) {
    System.out.println("token exchange failed: " + e.error().orElse("?") + " " + e.errorDescription().orElse(""));
}
try {
  await client.read(url);
} catch (e) {
  if (e instanceof NotFoundError) {

  } else if (e instanceof UnauthorizedError) {
    console.log("not authenticated", e.challenges);
  } else if (e instanceof HttpError) {
    console.log(e.status, e.problem?.title ?? e.message);
  } else if (e instanceof AuthenticationError) {
    console.log("token exchange failed:", e.error, e.errorDescription);
  } else {
    throw e;
  }
}

    client.read(url);
} catch (const lws::NotFoundError&) {
    std::cout << "no such resource\n";
} catch (const lws::UnauthorizedError& e) {
    std::cout << "not authenticated (" << e.challenges().size() << " challenges)\n";

    Ok(resource) => println!("{} bytes", resource.body.len()),
    Err(e) if e.is_not_found() => println!("no such resource"),
    Err(Error::Unauthorized(http)) => println!("not authenticated: {:?}", http.challenges),
    Err(Error::Authentication { error, error_description, .. }) => {
        println!("token exchange failed: {error:?} {error_description:?}")
    }
    Err(e) if e.status().is_some() => {
        println!("{:?} {:?}", e.status(), e.problem().and_then(|p| p.title.clone()))
    }
    Err(e) => return Err(e),
}

} catch (UnauthorizedException $e) {
    echo 'not authenticated: ', count($e->challenges()), " challenge(s)\n";
} catch (HttpException $e) {                         // any other error status
    echo $e->status, ' ', $e->problem->title ?? $e->getMessage(), "\n";
} catch (AuthenticationException $e) {
    echo 'token exchange failed: ', $e->oauthError ?? '?', ' ', $e->oauthErrorDescription ?? '', "\n";
} catch (TransportException $e) {
    echo $e->isTimeout() ? "timed out\n" : $e->getMessage() . "\n";
}

Problem details

When an error response has an RFC 9457 body (application/problem+json), the error carries it as problem: type, title, status, detail, instance and any extension members. The raw response body is kept too (Python, C#, Swift and PHP keep the first 4 KiB).

try {
    client.delete(container);
} catch (ConflictException e) {
    e.problem().ifPresent(p -> System.out.println(p.type() + " " + p.title() + " " + p.detail()
            + " " + p.instance() + " " + p.extensions().get("itemCount")));
}
try {
  await client.delete(container);
} catch (e) {
  if (e instanceof ConflictError && e.problem) {
    const { type, title, detail, instance, extensions } = e.problem;
    console.log(type, title, detail, instance, extensions["itemCount"]);
  }
}

    }
}

304 and 206 are not errors A conditional read that returns 304 Not Modified yields a normal result flagged notModified, and 206 Partial Content is a normal success.
